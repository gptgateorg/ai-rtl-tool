## دربارهٔ GptGate

وقتی فارسی، انگلیسی و فرمول‌های ریاضی کنار هم قرار می‌گیرند، رابط ابزارهای هوش مصنوعی همیشه نتیجهٔ خوبی نمایش نمی‌دهد. جهت متن جابه‌جا می‌شود، نشانه‌گذاری‌ها سر جای خود نیستند و خواندن فرمول‌ها سخت می‌شود.

GptGate این مشکلات را در همان ابزارهایی که هر روز استفاده می‌کنید برطرف می‌کند. می‌توانید جهت پاسخ‌ها و کادر نوشتن را جداگانه کنترل کنید و متن‌های دوزبانه و فرمول‌های ریاضی را مرتب‌تر ببینید.

GptGate بر پایهٔ Chrome Manifest V3 ساخته شده و نسخهٔ فعلی آن `0.1.1` است.

## قابلیت‌ها

- تنظیم جداگانهٔ حالت `RTL`، `LTR` یا تشخیص خودکار برای پاسخ‌ها و کادر نوشتن
- تشخیص هوشمند جهت متن فارسی و انگلیسی
- نمایش بهتر فرمول‌های KaTeX و MathJax در محتوای راست‌چین
- استفاده از فونت IRANSansX برای خوانایی بیشتر متن فارسی
- تم تیرهٔ اختصاصی برای Claude
- ذخیرهٔ تنظیمات در مرورگر
- اعمال تغییرات روی تب‌های پشتیبانی‌شده بدون ایجاد وقفه در گفتگو

## سرویس‌های پشتیبانی‌شده

| سرویس | وب‌سایت |
| --- | --- |
| ChatGPT | `chatgpt.com` و `chat.openai.com` |
| Gemini | `gemini.google.com` |
| Claude | `claude.ai` |

## نصب از سورس

برای ساخت افزونه به موارد زیر نیاز دارید:

- Node.js 18 یا جدیدتر
- npm
- یک مرورگر مبتنی بر Chromium مانند Google Chrome یا Microsoft Edge

وابستگی‌ها را نصب کنید و نسخهٔ نهایی را بسازید:

```bash
npm ci
npm run build
```

برای بارگذاری افزونه در Chrome:

1. آدرس `chrome://extensions` را باز کنید.
2. گزینهٔ **Developer mode** را فعال کنید.
3. روی **Load unpacked** بزنید.
4. پوشهٔ ساخته‌شدهٔ `dist` را انتخاب کنید.

در Microsoft Edge نیز می‌توانید همین مراحل را از آدرس `edge://extensions` انجام دهید.

## استفاده از GptGate

یکی از سرویس‌های ChatGPT، Gemini یا Claude را باز کنید و از نوار ابزار مرورگر روی نشان GptGate بزنید. جهت پاسخ‌ها و کادر نوشتن را می‌توانید روی `RTL`، `LTR` یا حالت خودکار قرار دهید. تنظیمات تکمیلی برای نمایش فرمول‌های ریاضی، فونت فارسی و تم تیرهٔ Claude نیز در دسترس هستند.

انتخاب‌های شما به‌صورت خودکار ذخیره می‌شوند و روی تب‌های پشتیبانی‌شده اعمال خواهند شد.

## توسعه

اجرای محیط توسعه:

```bash
npm run dev
```

ساخت نسخهٔ نهایی:

```bash
npm run build
```

نسخهٔ قابل بارگذاری افزونه در پوشهٔ `dist` ساخته می‌شود.

## ساختار پروژه

```text
gptgate-browser-extension/
├── manifest.json          # تنظیمات Manifest V3
├── background.js          # سرویس‌ورکر افزونه
├── popup.html             # رابط پنجرهٔ افزونه
├── popup.js               # منطق تنظیمات و تعاملات پنجره
├── src/
│   ├── shared/            # منطق و تنظیمات مشترک
│   ├── chatgpt/           # یکپارچه‌سازی ChatGPT
│   ├── gemini/            # یکپارچه‌سازی Gemini
│   └── claude/            # یکپارچه‌سازی Claude
├── images/                # تصاویر و نشان افزونه
└── fonts/                 # فونت رابط کاربری
```

## مجوزهای مرورگر

GptGate فقط مجوزهایی را درخواست می‌کند که برای کار در سرویس‌های پشتیبانی‌شده لازم هستند:

- `storage` تنظیمات شما را در مرورگر نگه می‌دارد.
- `tabs` تب‌های پشتیبانی‌شده را شناسایی و تغییرات را روی آن‌ها اعمال می‌کند.
- `scripting` در صورت نیاز ارتباط افزونه را با یک تب پشتیبانی‌شده دوباره برقرار می‌کند.
- دسترسی میزبان به دامنه‌های ChatGPT، Gemini و Claude محدود شده است.

## حریم خصوصی

GptGate محتوای گفتگوها یا تنظیمات شما را به سرور مستقلی ارسال نمی‌کند. تنظیمات در فضای ذخیره‌سازی مرورگر باقی می‌مانند. لینک تلگرام GptGate نیز فقط زمانی باز می‌شود که خودتان آن را انتخاب کنید.
